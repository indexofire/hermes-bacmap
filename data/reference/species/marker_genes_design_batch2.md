## 补充多基因组合判定规则

| 鉴别目标 | 基因组合 | 判定逻辑 |
|---|---|---|
| **B. anthracis vs B. cereus** | pagA + capB + rpoB | pagA(+)/capB(+) = B.anthracis（双质粒确认）；仅 groEF(+) = B.cereus group |
| **Y. pestis vs Y. pseudotuberculosis** | caf1 + pla | caf1(+) + pla(+) = Y.pestis（两质粒pMT1+pPCP1）；阴性 = 近缘耶尔森菌 |
| **C. botulinum 分型** | bont/A-F | 各型毒素基因互斥，直接确定毒素型 |
| **H. pylori 耐药** | 23S rRNA(A2143G等) | 23S rRNA 突变位点检测 → clarithromycin 耐药 |
| **L. interrogans vs 非致病钩体** | lipL32 + 16S rRNA | lipL32(+) = 致病性钩体；仅16S(+) = 腐生性/中间型 |
| **B. mallei vs B. pseudomallei** | bimA(Bm) vs bimA(Bp) | bimA 序列差异是金标准鉴别标记 |
| **B. pseudomallei vs B. thailandensis** | TTS1 + bimA(Bp) | B.thailandensis 无 TTS1→arsenal；B.pseudomallei TTS1(+) |
| **S. suis 血清2型** | gdh + cps2J | gdh(+) = S.suis；cps2J(+) = 血清2型（人畜共患主要型别） |
| **E. albertii vs E. coli** | eacF + uidA | eacF(+) + uidA(-) = E.albertii；uidA(+) = E.coli |
| **C. diphtheriae 产毒判定** | tox + dtxR | dtxR(+) = C.diphtheriae；tox(+) = 产毒株（需 toxigenicity test） |
| **百日咳 vs 副百日咳** | IS481 + IS1001 | IS481(+) + IS1001(-) = B.pertussis；IS481(+) + IS1001(+) = B.parapertussis |
| **产气荚膜梭菌分型** | cpa + cpb + etx + iA + cpe | cpa(+)单阳 = A型；+cpb=B型；+etx=D型；+iA=E型；cpe(+)=食物中毒株 |
