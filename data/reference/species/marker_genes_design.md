## 二、多基因组合判定规则

### 近缘种鉴别（需要 ≥2 个基因组合）

| 鉴别目标 | 基因组合 | 判定逻辑 | 依据 |
|---|---|---|---|
| **E. coli vs Shigella** | uidA + lacY | uidA(+) + lacY(+) → E. coli; uidA(+) + lacY(-) → 疑似 Shigella; ipaH(+) + lacY(-) → Shigella/EIEC | lacY 乳糖通透酶，Shigella 为乳糖阴性 | FDA BAM Ch.4 |
| **Shigella vs EIEC** | ipaH + lacY + uidA | ipaH(+) + lacY(-) + 任何 E. coli 生化标记 → EIEC; ipaH(+) + lacY(-) + 无 E. coli 标记 → Shigella | 两者基因高度相似，需综合判定 | PHE kmerID |
| **V. parahaemolyticus vs V. alginolyticus** | toxR + tlh | toxR(+) + tlh(≥90%) → V.para; toxR(-) + tlh(+) → 近缘弧菌; toxR(+) + tlh(≥90%) + tdh/trh(+) → 致病 V.para | tlh 单独 <90% 不可判定（已验证交叉反应） | 本项目验证 |
| **C. jejuni vs C. coli** | mapA + ceuE | mapA(+) + ceuE(-) → C. jejuni; mapA(-) + ceuE(+) → C. coli; mapA(+) + ceuE(+) → 混合/交叉 | 两基因种特异性互补 | FDA BAM |
| **L. monocytogenes vs L. innocua** | hly + prs | prs(+) + hly(+) → L. monocytogenes; prs(+) + hly(-) → 非致病 Listeria | hly 为种特异毒力基因 | FDA BAM Ch.10 |
| **K. pneumoniae vs K. quasipneumoniae** | khe + gyrB | khe(+) + gyrB(≥95%) → K. pneumoniae; khe(+) + gyrB(<95%) → 近缘 Klebsiella | gyrB 序列差异种间 >5% | 多文献 |
| **E. faecalis vs E. faecium** | ddl-Ef + ddl-Efm | ddl-Ef(+) → E. faecalis; ddl-Efm(+) → E. faecium | ddl 基因种间序列差异 | 多文献 |
| **S. pneumoniae vs 口腔链球菌** | lytA + psaA | lytA(+) + psaA(+) → S. pneumoniae; 仅 lytA(+) → 可能近缘 | S. mitis 含 lytA 同源基因 | 多文献 |
| **N. meningitidis vs N. lactamica** | ctrA + sodC | ctrA(+) + sodC(+) → N. meningitidis; sodC(+) + ctrA(-) → 共生奈瑟菌 | ctrA 为荚膜特异 | CDC |

### 致病性/毒力判定（在物种确认基础上）

| 病原 | 致病基因 | 阳性含义 |
|---|---|---|
| V. parahaemolyticus | tdh + trh | tdh(+) = Kanagawa 阳性（胃肠炎）；trh(+) = 协同致病；双(+)=高致病 |
| STEC | stx1/stx2 + eae | stx + eae(+) = 典型 EHEC（如 O157:H7）；stx + eae(-) = 非典型 STEC |
| V. cholerae | ctxA/B | ctx(+) = 产毒株（流行）；ctx(-) = 非产毒（环境） |
| C. difficile | tcdA/tcdB + cdtA/B | tcd + cdt(+) = RT027/RT078 高产毒株 |
| S. aureus | femA + mecA | femA(+) = S. aureus; + mecA(+) = MRSA |
| B. cereus | ces vs nheB | ces(+) = 催吐型；nheB(+) = 腹泻型 |
| Y. enterocolitica | ail/yadA | ail/yadA(+) = 致病株；(-) = 非致病环境株 |

## 四、实施建议

### 基因获取方式
1. **NCBI Nucleotide**: 按 GenBank 登录号（如 M90846.1）下载参考序列
2. **NCBI Datasets CLI**: `datasets download gene taxon "Salmonella enterica" gene symbol invA`
3. **Pathogen Detection**: FTP Results 目录中的 AMR/virulence 基因集

### 数据库构建流程
```
1. 下载参考序列（FASTA）
2. 统一命名格式：>marker_db~~~gene_name~~~accession description
3. makeblastdb -in markers.fasta -dbtype nucl -out species_markers_v2
4. 更新 pathogens.yaml 注册新 marker_genes
5. 运行验证：validate_species_id.py --methods marker
```

### 阈值建议
- **种特异性基因**（invA, toxR, hly 等）: identity ≥ 90%, coverage ≥ 50%
- **近缘辅助基因**（tlh, uidA 等）: identity ≥ 90%, coverage ≥ 50%, 需组合判定
- **毒力基因**（stx, tdh, ctxA 等）: identity ≥ 85%, coverage ≥ 40%（更宽松，因变异大）
- **持家基因**（rpoB, gyrB 等）: identity ≥ 85%, coverage ≥ 80%（用于种内确认）

### 已知交叉反应（必须处理的）

| 基因 | 交叉物种 | 交叉率 | 处置 |
|---|---|---|---|
| tlh | V. alginolyticus | ~85% identity | 近缘守卫：<90% 不判定 |
| uidA | Shigella (44%), Salmonella (29%) | ~80-85% identity | 不能单独判定，需 lacY/ipaH 组合 |
| eae | Citrobacter, E. albertii | ~85% identity | 需结合其他标记 |
| 16S rRNA | 种内多拷贝异质 | ~99%+ | 不用于种级鉴定 |
| femA | S. epidermidis（低水平） | ~75% | 阈值过滤 |
