# *Campylobacter jejuni* / *C. coli*（空肠/结肠弯曲菌）

## 公卫意义

全球最常见细菌性食源性病原。*C. jejuni* 占 90% 以上临床病例。与 Guillain-Barré 综合征相关。

## 物种鉴定

| 方法 | 靶标 | 来源 |
|---|---|---|
| marker 鉴定 | *C. jejuni*: **mapA** + **cadF**；*C. coli*: **ceuE** | [Linton et al. 1997](https://doi.org/10.1128/jcm.35.11.2568-2572.1997) |

### 种间鉴别

| 基因 | C. jejuni | C. coli |
|---|---|---|
| mapA | + | - |
| hipO | + | - |
| ceuE | - | + |
| aspA | - | + |
