# 96-Strain Batch Benchmark

> Generated by: `python scripts/benchmark_batch.py` (V0.7 Wave 4).
> Linear extrapolation model: cost per read pair per strain is constant; the ≤8h target in §2.2
> is set for the recommended tier (24c/48t); local results must be rescaled by core count.

## Benchmark setup

- bench strains: **4** × 150,000 read pairs (downsampled from gold standard with seqkit)
- cores: **8** (AMD Ryzen 7 5700G, 8c/16t)
- measured wall time: **550.0s** (0.15h)

## Extrapolation to 96 strains

- 96 strains × 1,000,000 read pairs @ 8 cores: **88000s ≈ 24.4h**
- vs target ≤8h (recommended tier 24c/48t): ❌ not met

## Notes

- SPAdes assembly is the main bottleneck (project.md §7.4); shallow-depth downsampling makes the
  extrapolation optimistic, and full-depth per-strain runtime is higher — conclusions should be
  based on the full run.
- The benchmark batch is fully isolated: `samples_bench.tsv` + `results-bench/`, never touching
  production `results/`.
